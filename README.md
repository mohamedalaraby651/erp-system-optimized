# نظام ERP المتكامل - Enhanced ERP System

## 🚀 نظرة عامة

نظام إدارة موارد المؤسسات (ERP) شامل ومتطور يوفر إدارة كاملة لجميع عمليات الشركة بواجهة عربية حديثة مع دعم اللغة الإنجليزية.

## ✨ الميزات الرئيسية

### 📊 لوحة التحكم التفاعلية
- **إحصائيات لحظية**: عرض الإيرادات، الأرباح، الفواتير المعلقة، والعملاء
- **رسوم بيانية تفاعلية**: Chart.js مدمج لعرض الإيرادات والمصروفات وتوزيع المبيعات
- **بطاقات إحصائية ملونة**: تصميم جذاب مع تأثيرات انتقالية

### 🏢 إدارة الموارد البشرية (HR)
- **الموظفين**: إدارة كاملة للموظفين مع صفحات بروفايل تفصيلية
- **الحضور والانصراف**: تتبع حضور الموظفين وساعات العمل
- **الرواتب**: نظام الرواتب مع البدلات والخصومات
- **الإجازات**: إدارة إجازات الموظفين
- **تقارير الموارد البشرية**: تقارير شاملة عن الموظفين

### 💼 إدارة المبيعات (Sales)
- **العملاء**: إدارة قاعدة بيانات العملاء مع صفحات بروفايل
- **فواتير المبيعات**: إنشاء وطباعة فواتير مبيعات احترافية
- **العقود**: إدارة عقود العملاء
- **المعاملات المالية**: تتبع المدفوعات والمستحقات
- **إدارة علاقات العملاء (CRM)**: تسجيل التفاعلات مع العملاء
- **الفرص البيعية**: متابعة الفرص والصفقات

### 🛒 إدارة المشتريات (Purchasing)
- **الموردين**: إدارة قاعدة بيانات الموردين مع صفحات بروفايل
- **فواتير المشتريات**: إدارة فواتير الموردين
- **أوامر الشراء**: إنشاء ومتابعة أوامر الشراء
- **المخزون**: إدارة المخزون وتتبع الكميات
- **معاملات الموردين**: تتبع المدفوعات والمستحقات

### ⚙️ الإدارة العامة (Administration)
- **المستخدمين**: إدارة حسابات المستخدمين والصلاحيات
- **الأقسام**: تنظيم الأقسام والمديرين
- **الإعدادات**: إعدادات النظام العامة
- **الملف الشخصي**: تعديل البيانات الشخصية
- **السمات**: تبديل بين الأوضاع الفاتحة والداكنة

## 🛠️ التطوير المحلي

```bash
# تثبيت الاعتماديات
npm install

# تطبيق الـ Migrations
npm run db:migrate:local

# إضافة البيانات التجريبية
npm run db:seed

# البناء
npm run build

# التشغيل مع PM2
pm2 start ecosystem.config.cjs

# عرض اللوجات
pm2 logs webapp --nostream

# إعادة التشغيل
fuser -k 3000/tcp && pm2 restart webapp
```

## 🚀 النشر على Cloudflare Pages
