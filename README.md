## 🏗️ هيكل قاعدة البيانات

### الجداول الرئيسية

1. **إدارة المستخدمين والصلاحيات**
   - `roles` - الأدوار (مدير، محاسب، موظف، إلخ)
   - `permissions` - الصلاحيات التفصيلية لكل دور
   - `users` - المستخدمين

2. **الهيكل التنظيمي**
   - `departments` - الأقسام
   - `employees` - الموظفين

3. **إدارة العلاقات**
   - `clients` - العملاء
   - `suppliers` - الموردين
   - `client_interactions` - تفاعلات العملاء (CRM)
   - `opportunities` - الفرص البيعية

4. **النظام المحاسبي**
   - `accounts` - دليل الحسابات
   - `journal_entries` - القيود المحاسبية

5. **الفواتير والمدفوعات**
   - `invoices` - الفواتير (مبيعات ومشتريات)
   - `invoice_items` - بنود الفواتير

6. **المخزون**
   - `inventory_items` - الأصناف
   - `inventory_transactions` - حركات المخزون

7. **الموارد البشرية**
   - `attendance` - الحضور والانصراف
   - `leaves` - الإجازات
   - `payroll` - الرواتب

8. **العقود والوثائق**
   - `contracts` - العقود

9. **النظام**
   - `audit_logs` - سجل الأنشطة
   - `notifications` - الإشعارات
   - `settings` - الإعدادات العامة

## 🚀 المميزات الرئيسية

### 1. نظام المصادقة والصلاحيات
- تسجيل دخول آمن باستخدام JWT
- نظام أدوار متعدد المستويات (Admin, Manager, Accountant, HR Manager, Employee)
- صلاحيات تفصيلية لكل قسم (إنشاء، قراءة، تعديل، حذف، تصدير)
- حماية API endpoints بناءً على الصلاحيات

### 2. لوحة التحكم التفاعلية
- إحصائيات مالية شاملة (إيرادات، مصروفات، صافي الربح)
- عدادات للعملاء، الموردين، الموظفين
- تتبع الفواتير (معلقة، متأخرة، مدفوعة)
- واجهة عصرية ومتجاوبة

### 3. إدارة المستخدمين
- إضافة وتعديل وحذف المستخدمين
- تعيين الأدوار والصلاحيات
- تغيير كلمة المرور
- تتبع آخر تسجيل دخول

### 4. النظام المحاسبي
- دليل حسابات شامل (أصول، خصوم، حقوق ملكية، إيرادات، مصروفات)
- قيود محاسبية مزدوجة القيد
- تقارير مالية (قائمة الدخل، الميزانية العمومية)
- تتبع الأرصدة الحالية

### 5. إدارة العملاء والموردين
- قاعدة بيانات شاملة للعملاء والموردين
- تتبع التفاعلات والفرص البيعية
- إدارة حدود الائتمان وشروط الدفع
- تقارير تحليلية

### 6. نظام الفواتير
- إصدار فواتير مبيعات ومشتريات
- حساب تلقائي للضرائب والخصومات
- تتبع حالة الدفع
- ربط بالحسابات المحاسبية

### 7. إدارة الموارد البشرية
- سجلات كاملة للموظفين
- نظام الحضور والانصراف
- إدارة الإجازات
- حساب الرواتب والمستحقات

### 8. إدارة المخزون
- تسجيل الأصناف والمنتجات
- تتبع حركات المخزون
- تنبيهات إعادة الطلب

## 🔌 API Endpoints

### المصادقة
- `POST /api/auth/login` - تسجيل الدخول
- `GET /api/auth/me` - بيانات المستخدم الحالي
- `POST /api/auth/change-password` - تغيير كلمة المرور

### المستخدمين
- `GET /api/users` - قائمة المستخدمين (مع البحث والصفحات)
- `GET /api/users/:id` - بيانات مستخدم محدد
- `POST /api/users` - إضافة مستخدم جديد
- `PUT /api/users/:id` - تعديل مستخدم
- `DELETE /api/users/:id` - حذف مستخدم
- `GET /api/users/roles/list` - قائمة الأدوار

### لوحة التحكم
- `GET /api/dashboard/stats` - إحصائيات لوحة التحكم
- `GET /api/dashboard/activities` - الأنشطة الأخيرة
- `GET /api/dashboard/notifications` - الإشعارات
- `PUT /api/dashboard/notifications/:id/read` - وضع علامة مقروء

### ملاحظة
جميع الـ endpoints (ما عدا `/api/auth/login`) تتطلب Authorization header:
```
Authorization: Bearer <token>
```

## 📦 التثبيت والتشغيل المحلي

### المتطلبات
- Node.js 18+
- npm أو yarn
- PM2 (للتشغيل في الخلفية)

### خطوات التثبيت

1. **تثبيت المكتبات**
```bash
cd /home/user/webapp
npm install
```

2. **تطبيق migrations**
```bash
npm run db:migrate:local
```

3. **إضافة البيانات الأولية**
```bash
npm run db:seed
```

4. **بناء المشروع**
```bash
npm run build
```

5. **تشغيل النظام**
```bash
# باستخدام PM2
pm2 start ecosystem.config.cjs

# أو مباشرة
npm run dev:d1
```
