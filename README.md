## 🚀 التطوير المحلي

### المتطلبات
- Node.js 18+
- npm أو yarn

### التثبيت
```bash
# استنساخ المشروع
git clone https://github.com/mohamedalaraby651/erp-system-optimized.git
cd erp-system-optimized

# تثبيت الحزم
npm install

# إعداد قاعدة البيانات
npm run db:migrate:local

# بناء المشروع
npm run build

# تشغيل محلياً
npm run preview
```

الموقع متاح على: http://localhost:4173

## 📦 النشر

### Cloudflare Pages (موصى به)
```bash
# تثبيت Wrangler
npm install -g wrangler

# تسجيل الدخول
wrangler login

# إنشاء قاعدة البيانات
wrangler d1 create erp-production

# تطبيق Migrations
wrangler d1 migrations apply erp-production

# بناء المشروع
npm run build

# النشر
wrangler pages deploy dist --project-name erp-system
```
